# duel_battle
Tactical Party Battle 
PythonとStreamlitを用いてブラウザ上で手軽に遊べる、本格的なタクティカル・ターン制バトルゲームアプリケーションです。プレイヤーは6人の異なるクラスを率いて、全10ステージの魔王討伐を目指します。  
主な機能
3×6の戦場マップシステム: 3行6列のグリッド上で、味方キャラクターと敵キャラクターの位置を視覚的に管理しながら戦闘を行います。  
多彩な6つのプレイヤークラス: ナイト、ウォーリア、ローグ、メイジ、アーチャー、プリーストの6名がそれぞれの固有スキルカードを駆使して戦います。  
カード選択式アクション: 「移動」「攻撃」「回復」などのアクションカードを選択し、射程範囲や属性、毒などの状態異常を考慮した戦略的なコマンド入力が可能です。  
敵の列シフト機構: 敵の前衛が倒されると、後方の敵が自動で前進して隙間を埋める動的な陣形システムを搭載しています。  
ステージインフレと報酬システム: ステージをクリアするごとに、味方の最大HPやスキル威力が1.2倍に自動成長し、難易度の上がる後半ステージへ挑むことができます。  
使用技術言語: Python  
フレームワーク: Streamlit  
起動方法
リポジトリをクローンまたはダウンロードします。  
ターミナルから必要なライブラリ（Streamlit）をインストールします。  
pip install streamlit
アプリケーションを保存したディレクトリで以下のコマンドを実行します。  
streamlit run app.py
